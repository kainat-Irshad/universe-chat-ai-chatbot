# universe-chat-ai-chatbot
AI-powered chatbot built during internship at Decode Lab# 🌌 UNIVERSE CHAT

Aapka personal AI chatbot — Urdu aur English dono mein!

## Shuru Karne Ka Tarika

### Step 1 — Setup
Windows pe double-click karein: `setup.bat`

### Step 2 — Start
```
cd backend
npm start
```

### Step 3 — Kholo
Browser mein: http://localhost:3001

## API Key
`backend/.env` file mein pehle se set hai.

## Features
- Urdu + English support
- Space/Galaxy dark theme
- Streaming responses (real-time)
- Suggestion buttons
- Mobile friendly
